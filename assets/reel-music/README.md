# Tracce musicali per i Reel

Carica qui i file audio **royalty-free** (`.mp3`, `.m4a`, `.aac`, `.wav`).

- Ogni file diventa automaticamente una voce selezionabile nel menù
  "Crea Reel" della dashboard (l'etichetta è il nome del file, con gli
  underscore trasformati in spazi).
- Esempio: `bottega_calma.mp3` → voce "Bottega calma".
- Usa solo musica royalty-free per evitare problemi di copyright su
  Instagram/Facebook. In alternativa puoi generare reel "Senza musica"
  e aggiungere l'audio direttamente nell'app social.
